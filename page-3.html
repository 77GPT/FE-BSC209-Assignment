1. Introduction to HTML

HTML stands for HyperText Markup Language. It is used to structure content on web pages.

HTML uses elements and tags to organise headings, paragraphs, images and links.

2. Semantic Elements

Semantic elements describe the meaning and purpose of the content they contain.

Examples include header, nav, main, section, article, aside and footer.

3. The Header Element

The header element usually contains introductory content for a page or section.

It can contain a heading, a logo, introductory text or navigation links.

4. The Navigation Element

The nav element contains important navigation links for a website.

Navigation links help visitors move between different pages or sections.

5. The Main and Section Elements

The main element contains the primary content of a web page.

The section element groups related content together under a common topic.

6. The Footer Element

The footer element contains information about a page or section.

It may include copyright information, contact details or links to other resources.
