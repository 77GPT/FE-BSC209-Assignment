1. Introduction to HTML

HTML stands for HyperText Markup Language. It is used to structure content on web pages.

HTML uses elements and tags to organise headings, paragraphs, images and links.

2. Semantic Elements

Semantic elements describe the meaning and purpose of the content they contain.

Examples include header, nav, main, section, article, aside and footer.

3. Why Semantic HTML Matters

Semantic HTML makes websites easier to understand, maintain and navigate, including for people using assistive technology.
